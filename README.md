# Univesity-Department-Student-Grading-Program
This program takes in students informations and calculates their GPA using the logic of the program. This Porgram is designed to be user friendly and easy to use. It is designed to be used by university departments to manage student grades and calculate their GPA efficiently. The programs allows users to input student informations.

# Programming language used
Tis program is written in GOlang programming language. GOlang is statically typed, compiled programming language designed at Google. It is syntactically similar to C,  but with memory safety, garbage collection, structural typing, and CSP-style convurrency.

# What was the biggest technical challenge faced, and how did i fixed it?
The biggest technical challenge faced was implementing the GPA calculation logic. Initially, i struggled with understanding the grading system and how to convert letter grades to grade pints. To fix this, I researched the grading system used by universities and created a mapping of letter ggrades to grade points. I then implemented the logic to calculate the GPA based on the grade points and the number of courses taken by the student. This allowed me to accurately calculate the GPA for each student.

## How to run the program
To run the program, follow these steps:
1. Clone the repository to your local machine.
2. Open a terminal and navigate to the project directory.
3. Run the command `go run main.go` to start the program.
